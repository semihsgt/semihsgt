## 📱 Projects

### 🎬 [Movie Mind](https://github.com/semihsgt/MovieMindApp_SwiftUI)

<sub>`SwiftUI` `SwiftData` `Swift Concurrency` `Gemini API` `TMDB API`</sub>

An AI-powered iOS app for discovering movies, TV shows and people. Gemini generates the suggestions, grounded in real TMDB data so the results stay accurate instead of hallucinated.

- LLM integration with structured JSON schema output
- TMDB REST API over `URLSession` with async/await
- Local persistence with SwiftData

### 🌤 [Atlas Weather](https://github.com/semihsgt/AtlasWeatherApp_SwiftUI)

<sub>`SwiftUI` `MVVM` `REST APIs` `JSON`</sub>

A native iOS weather app built with SwiftUI and MVVM. Real-time conditions from OpenWeatherMap, country data parsed from a local JSON file, and location visuals pulled from the Unsplash API.

- Three data sources combined into a single view model layer
- Local JSON decoding with `Codable`
- MVVM separation between networking, state and UI
